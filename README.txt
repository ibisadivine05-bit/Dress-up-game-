# Style Battle: Underdog — free prototype

This is a mobile-friendly browser game prototype. Open `index.html` in a browser.
For phone testing, upload the folder to a static host such as GitHub Pages.

Features:
- 10 escalating levels
- countdown timer
- clothing categories and selectable items
- hairstyle, accessories and makeup
- scoring, win/lose states and coins
- unlock progression
- different challenge clues and scoring rules
- responsive mobile UI

This prototype intentionally uses CSS/emoji art so it can run with no external assets or paid services. The next production phase can replace the character with illustrated/game assets, add sound, save progress, rivals, animations, and richer challenge logic.
